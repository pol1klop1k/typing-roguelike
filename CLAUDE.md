# TYPING ROGUELIKE

Роглайт про скоростную печать, вдохновлённый Balatro.
Игрок печатает текст на время, ошибки отнимают секунды.

Сеттинг: последний выживший человек в эпоху сошедшего с ума искусственного
интеллекта (в духе «У меня нет рта, но я должен кричать»). Игрок узнаёт лор
из текстов, которые печатает. Боссы — кульминационные моменты: битвы с
LLM-моделями, уничтожение центров обработки данных, встречи с неизвестным Neo.

## С чего начать сессию

**Прочитать `docs/status.md`.** Там текущее состояние, открытые долги, что
проверено руками и что нет, и особенности окружения.

Перед работой над подсистемой — её документ. Они написаны как раз для того,
чтобы не выводить заново то, что уже решено:

| Подсистема | Документ |
|---|---|
| Кривая сложности, цель узла, таймер | `docs/difficulty.md` |
| Предметы, хуки эффектов, редкость | `docs/items.md` |
| Боссы: привязка к узлу, Сиделка | `docs/bosses.md` |
| Кредиты: начисление, траты, сток | `docs/economy.md` |
| Админка и `tuning.json` | `docs/tuning.md` |
| Тексты, слоты, варианты, показ на экране | `docs/content.md` |
| Канон вселенной, правила письма текстов | `lore.md` |

`src/content/tuning.json` — рабочий файл продуктового менеджера с
подобранным балансом. **Не перезаписывать его** ни при проверках, ни при
отладке: см. `docs/tuning.md`.

## Команды

```
npm run dev     # запуск разработки; админка на #admin
npm run test    # тесты игрового ядра
npm run build   # сборка

npx tsc -b --noEmit   # проверка типов отдельно
```

Проверка в браузере — за человеком: из песочницы агента сеть недоступна,
дев-сервер оттуда не открыть. Игровую логику агент проверяет симуляцией
уровня через настоящее ядро (`LevelSession`), а не только юнит-тестами.
